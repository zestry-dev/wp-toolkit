# BadgeColor

The colour of the category badge beside a check's label.

WordPress renders it as a class name — `<span class="badge {color}">` — and styles exactly these six. Any other string produces an unstyled badge, which looks like a bug in your plugin rather than a typo, and nothing warns you. A closed set is the fix.
